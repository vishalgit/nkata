# The pull-request template

**File:** `.github/pull_request_template.md`  
**Save to:** `~/code/todo/.github/pull_request_template.md`

## Goal
Type the PR template: every PR names its story and task and ticks the Definition of Done.

## Why
- `Part of #<story>` links the PR to its story; `Closes #<task>` closes the task issue on merge.
- The PR that finishes a story's last task also says `Closes #<story>`.
- The checklist is the Definition of Done from "How to use this guide". Items that need a later chapter (the pipeline, `.sqlx/`, the dashboard) apply once that chapter has built them.
