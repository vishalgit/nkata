# The user-story issue template

**File:** `.github/ISSUE_TEMPLATE/story.yml`  
**Save to:** `~/code/todo/.github/ISSUE_TEMPLATE/story.yml`

## Goal
Type the issue form for user stories.

## Why
- A GitHub issue form: each `body` item becomes a field. `validations: { required: true }` refuses an empty field.
- The acceptance criteria field asks for the test name, the same way every card in this guide does.
