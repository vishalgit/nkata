# The dark theme

**File:** `style/themes/_dark.scss`  
**Save to:** `~/code/todo/style/themes/_dark.scss`

## Goal
Dark mode is just new values for the same properties.

## Why
No component knows about themes: they all read `var(--color-…)`. The focus colour is left as it is; it reads well on both.
