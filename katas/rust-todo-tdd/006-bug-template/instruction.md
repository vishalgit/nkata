# The bug issue template

**File:** `.github/ISSUE_TEMPLATE/bug.yml`  
**Save to:** `~/code/todo/.github/ISSUE_TEMPLATE/bug.yml`

## Goal
Type the bug form: a bug is behaviour that contradicts an acceptance criterion, so it names the story it breaks.

## Why
The last field asks for the failing test that will prove the fix: a bug fix starts red, like everything else.

## Help
- Save with `:w! ~/code/todo/.github/ISSUE_TEMPLATE/bug.yml`.
