# Showcase page styles

**File:** `style/pages/_showcase.scss`
**Save to:** `~/code/design-kit/style/pages/_showcase.scss`

## Goal
Write the page-specific rules for the component review page.

## Why
- `pages/` is for rules that only make sense on one page: the swatch grid, the variant matrix, the card grid.
- If a rule here starts appearing on a second page, move it to `components/` or `layout/`.
- `&__scroll { overflow-x: auto; }` lets the variant table scroll on a phone instead of widening the page.
