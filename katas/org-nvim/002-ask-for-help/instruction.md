# Ask for help

## Goal
Never get lost: learn to read the key list with `g?`.

## What to do
- Press `g?` in the editor. A window lists every key that works here.
- Fill in each blank after `::` with the key you found.
- Then open the agenda (`<prefix>a` then `a`), press `g?` there, and fill the second list.

## Help
- `<prefix>` means `<leader>o`. `u` undoes, `<leader>kr` resets the kata.
- Write keys in `<prefix>` form, like `<prefix>s`, even if the help shows `<leader>o`.
- Agenda keys are single keys, like `q`.
