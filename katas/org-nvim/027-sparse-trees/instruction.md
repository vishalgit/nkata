# Sparse trees

## Goal
Fold the file so only matches are visible.

## What to do
- `<prefix>/` then `m` and type `+work`. Only work entries stay open. Look.
- `<S-Tab>` to show everything, `<C-c><C-c>` to clear the highlights.
- `<prefix>/` then `t`: only open TODOs.
- Walk the hits with `:lnext` and `:lprev`. On each hit press `<prefix>,` then `a`.

## Help
- `<prefix>` means `<leader>o`. `u` undoes, `<leader>kr` resets the kata.
- Other keys after `<prefix>/`: `/` regexp, `d` deadlines, `p` property value, `c` clear.
