# Type dates like you speak

## Goal
Use the date prompt as a language.

## What to do
Press `<prefix>s` on each task, then `i` inside the calendar, and type:
- `Kick-off call` → `8.1.2027`
- `Quarterly review` → `2027-03-01 14:00`
- `Workshop` → `15.3.2027 10:00+1:30` (start time plus a duration)

## Help
- `<prefix>` means `<leader>o`. `u` undoes, `<leader>kr` resets the kata.
- More to try (they depend on today, so they are not checked): `+3d` `-2w` `+1m` `fri` `+2fri`
  `sep 15` `tomorrow 14:00` `fri 14:00` `w40`. Try each, look, then retype the checked one.
- Calendar keys: `h j k l` day/week, `H L` month, `J K` year, `.` today, `T` set time.
