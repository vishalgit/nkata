# Lists

## Goal
Make lists behave.

## What to do
- On `dash` press `<S-Right>` once. The bullet changes for the whole list.
- On `third` press `<M-k>` twice. The numbers fix themselves.
- On the last description item press `<M-CR>` and add `org.nvim :: both of the above`.

## Help
- A description list is just `- term :: meaning`.
- Keep pressing `<S-Right>` to see every bullet style, then come back to `+`.
