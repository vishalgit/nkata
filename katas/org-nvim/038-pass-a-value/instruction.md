# Pass a value with :var

## Goal
Connect blocks, so one feeds the next.

## What to do
- Change `21` to `50`.
- Run the first block (it has a name). Then run the second. It reads the first one's result.

## Help
- `<prefix>` means `<leader>o`. `u` undoes, `<leader>kr` resets the kata.
- More header arguments to explore: `:noweb`, `:wrap`, `:cache`, `:file`, `#+CALL`. Add one with `<prefix>bj`.
