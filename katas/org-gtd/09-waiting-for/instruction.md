# 09 Waiting For: set a follow-up date

When someone owes you something, write down the day you will check again.
Use a scheduled date for this. It makes the item show up in the agenda on
that day.

## Goal

| Item                                        | Check again          |
|---------------------------------------------|----------------------|
| WAITING Quote from the plumber              | `2026-11-06`         |
| WAITING Reply from the landlord ...         | `2026-11-09`         |

## Steps

1. Put the cursor on the first headline.
2. Press `<prefix>s`. A calendar opens.
3. Press `i`, type `2026-11-06` and press `<CR>`.
4. Do the same for the second item with `2026-11-09`.

A line `SCHEDULED: <2026-11-06 Fri>` appears under the headline. The weekday
is added for you.
