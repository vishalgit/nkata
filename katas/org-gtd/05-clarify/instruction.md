# 05 Clarify (step 2 of GTD)

Now look at each Inbox item and ask:

- Can I act on it? If **no**, is it a "maybe later" (`SOMEDAY`) or trash
  (`CANCELLED`)?
- If **yes**: do I do it myself (`NEXT`), or am I waiting for someone
  (`WAITING`)?

## Goal

Give every Inbox item the right state.

| Item                                    | State       |
|-----------------------------------------|-------------|
| Call the dentist                        | `NEXT`      |
| Reply from the landlord about the heating | `WAITING` |
| Write a blog post about org mode        | `SOMEDAY`   |
| Fix the typo in an old note             | `CANCELLED` |

## Steps

1. Put the cursor on a headline.
2. Press `<prefix>T` and pick the state. Or press `cit` again and again to
   step to the next state (`ciT` goes back).
3. Do the same for all four.

## Done when

Your file matches `expected.org`. Nothing moved yet. Only the states changed.
