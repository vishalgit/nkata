# 11 Reflect: the weekly review (step 4 of GTD)

The weekly review keeps the whole system honest. It is a task that comes back
every week, with a checklist.

## Goal

Make `Weekly review` repeat every week, and tick the first three checklist
items.

## Steps

1. Put the cursor on the date `<2026-11-06 Fri>`.
2. Go right before the `>` and type ` ++1w` so it reads
   `<2026-11-06 Fri ++1w>`.
3. Put the cursor on `- [ ] Empty the inbox` and press `<C-Space>`.
4. Do the same for `Review next actions` and `Review waiting for`.
5. Look at the headline. The counter now says `[3/5]`.

## What does `++1w` mean?

When you mark the task DONE, the date jumps one week ahead (keeping the same
weekday) and the task becomes TODO again. (Do not mark it DONE in this kata.)
