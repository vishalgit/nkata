# 03 Build the five lists

GTD keeps your stuff in a few simple lists. Each list is one top-level
headline.

## Goal

Create these five headlines, in this order:

1. `Inbox`: everything new lands here
2. `Next Actions`: things you can do now
3. `Projects`: goals with more than one step
4. `Waiting For`: things other people owe you
5. `Someday/Maybe`: ideas for later

## Steps

1. Open `start.org`. Go to the last line.
2. Type `* Inbox`.
3. With the cursor on that line press `<M-CR>`. A new headline appears below.
4. Type the next name. Repeat until all five exist.

(You can also just press `o` and type `* ` each time.)

## Done when

Your file matches `expected.org`. All five headlines are level 1 (one star),
and none of them has TODO in front.
