# 02 Set up your contexts

A context tells you where or with what you can do a task: at home, on the
phone, at the computer. In org we use tags for this.

## Goal

Define your GTD tags once, so you can use short keys later.

## Steps

1. Open `start.org`. Go to the last line.
2. Press `o` and type this line exactly:

   `#+TAGS: @home(h) @office(o) @phone(p) @computer(c) @errands(e) project(j)`

3. Press `<Esc>`, then `<C-c><C-c>` on that line.

## How to read the line

- `@home(h)` is a tag called `@home`. Press `h` in the tag menu.
- `project(j)` is the tag we use for projects (kata 07). It must be called
  `project`.

## Done when

Your file matches `expected.org`.
