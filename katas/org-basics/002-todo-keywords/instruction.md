# TODO keywords and priorities

## Goal
The editor starts with an inbox of plain headings. Turn them into tasks so
they match the final result.

## What to do
- `Call the plumber` becomes a TODO with priority A.
- `Pay electricity bill` is already done, so mark it DONE.
- `Renew passport` becomes a plain TODO.
- Leave `Inbox` as it is.

## Help
- The keyword goes right after the stars: `** TODO Call the plumber`.
- A priority cookie goes after the keyword: `** TODO [#A] ...`.
- If org.nvim has a mapping to cycle TODO states or set a priority, use it
  instead of typing; the final text is what gets checked.
