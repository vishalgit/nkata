# 03 Write the sentence

You do not run anything here. You write the quick add line for each job.
Then you check your line in the live preview (`<prefix>q`) and see if it makes
the task you meant.

## The sentence rules

One line in. A full task out. Write the parts **in this order**:

1. the title (plain words)
2. a date and time, like `fri 3pm`
3. `#tag`
4. `!A` for priority
5. `~30m` for effort
6. `@Inbox` for the heading to file it under
7. `due mon` for a deadline
8. `every week` for a repeat

Skip any part you do not need. The example from the guide is:

`Call Bob fri 3pm #work !A ~30m @Inbox due mon every week`
