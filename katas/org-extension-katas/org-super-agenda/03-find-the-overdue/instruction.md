# 03 Read the overdue group

Dates in the past make a task **overdue**. A good grouped agenda puts these
first so you cannot miss them. Today you only read. You write what you see.

## Goal

List the overdue tasks, in the order they appear in the file.

## Steps

1. Add this file to the agenda for this session with `<C-c>[`.
2. Open the day agenda (`<prefix>a`, then `a`).
3. Find the overdue tasks. Super agenda shows them together.
4. Under the headline in `start.org`, type each overdue title as a list item
   (`- Title`).

The deadlines are far in the past (January and February 2026) and far in the
future (2037), so the answer does not change with the day you do this.

## Done when

Your file matches `expected.org`.
