# 04 Move a deadline from the chart

`D` changes the deadline the same way `S` changes the schedule.

## Goal

The launch is late. Move the deadline of "Launch the site" to **2026-11-27**.

## Steps

1. Open `start.org` and run `:Org timeline`.
2. Put the cursor on the row of "Launch the site".
3. Press `D`. In the date prompt press `i`, type `2026-11-27`, press `<CR>`.
4. Look at the bar. It is now longer.
5. Press `q` and save with `:w`.

## Done when

Your file matches `expected.org`.
